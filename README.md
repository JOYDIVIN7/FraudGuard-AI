# FraudGuard-AI
FraudGuard AI — Plateforme intelligente de détection de fraude bancaire Développement d'une solution end-to-end de détection de transactions suspectes utilisant Machine Learning, Explainable AI et API REST. Mise en place d'un pipeline de traitement des données, entraînement et comparaison de modèles, explicabilité SHAP, API FastAPI, PostgreSQL.
